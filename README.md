# 📊 데이터 실무 코치 (Data Practice Coach) - 로컬 AI 챗봇

> **Ollama와 경량 로컬 LLM(`gemma4:e2b`)을 기반으로 동작하는 Windows용 데이터 분석 실무 컨설팅 데스크톱 챗봇입니다.**

데이터 분석을 공부하고 있거나 실무 업무 적용을 준비하는 분들을 위해 단순 문법 위주가 아닌 **"업무 문제 → 필요 데이터 → KPI/지표 → 분석 방법 → 업무 의사결정"** 흐름으로 가이드를 제공합니다.

---

## ✨ 주요 기능

1. **실무 중심 시스템 프롬프트 탑재**
   - 불필요한 전문용어나 문법 나열을 지양하고, 실제 기업 업무 상황에 맞춘 5문장 내외의 명확한 실무 컨설팅 제공
   - 존재하지 않는 수치나 사례를 지어내지 않는 엄격한 원칙 적용

2. **문서 및 데이터 파일 첨부 분석**
   - **PDF (`.pdf`)**: `pypdf`를 통한 페이지별 본문 텍스트 추출 및 요약
   - **정형 데이터 (`.csv`, `.tsv`)**: 한글 인코딩 자동 감지, 전체 행/열 요약 및 상위 데이터 테이블 미리보기
   - **엑셀 (`.xlsx`, `.xls`)**: `openpyxl`을 통한 시트별 컬럼 및 데이터 분석
   - **텍스트/코드 (`.txt`, `.md`, `.py`, `.sql`, `.json`, `.log`)**: 코드 및 문서 본문 분석

3. **윈도우 전용 경량 GUI (Tkinter)**
   - 외부 무거운 웹 프레임워크 없이 파이썬 기본 GUI 모듈(`tkinter`)을 활용하여 가볍고 빠름
   - `Enter` 전송, `Shift + Enter` 줄바꿈 지원
   - 이전 대화 문맥(`messages`) 자동 기억
   - `[새 대화]` 버튼을 통한 대화 초기화
   - Ollama 서버 미실행 시 사용자 친화적인 안내 메시지 표출

4. **원클릭 실행 지원**
   - 복잡한 터미널 명령어 없이 `run_chat.bat` 더블 클릭만으로 즉시 실행 가능

---

## 🛠 사전 준비 사항

### 1. Ollama 설치 및 모델 다운로드
1. [Ollama 공식 홈페이지](https://ollama.com/)에서 Windows용 Ollama를 다운로드하여 설치합니다.
2. 터미널(PowerShell 또는 명령 프롬프트)을 열고 모델을 내려받습니다:
   ```bash
   ollama pull gemma4:e2b
   ```

### 2. 파이썬 의존성 설치 (선택 사항)
기본 채팅은 파이썬 기본 모듈만으로 동작합니다. PDF 및 Excel 파일 분석 기능을 사용하려면 아래 패키지를 설치합니다:
```bash
pip install -r requirements.txt
```

---

## 🚀 실행 방법

### 방법 1: 배치 파일 더블 클릭 (권장)
폴더 내의 **`run_chat.bat`** 파일을 더블 클릭합니다.

### 방법 2: 터미널에서 직접 실행
```bash
python local_chat.py
```

## ⚙️ 커스터마이징

- **모델 변경**: `local_chat.py` 상단의 `MODEL = "gemma4:e2b"` 변수를 원하는 Ollama 모델명(예: `llama3.2`, `qwen2.5:7b` 등)으로 변경할 수 있습니다.
- **역할/지침 수정**: 상단 `SYSTEM` 변수 문자열을 수정하여 챗봇의 페르소나와 답변 스타일을 원하는 대로 조정할 수 있습니다.
